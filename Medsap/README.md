# Медсап — прототип для показа куратору

Пациент заполняет анкету, а сайт показывает черновик сводки для врача. В демонстрационном режиме Python переносит заполненные поля в карточку. С подключённым OpenAI модель выбирает короткие цитаты из анкеты, распределяет их по разделам и предлагает уточнения из заданного списка.

Используйте вымышленные анкеты. Приложение запускается локально, без базы данных. В режиме с ИИ текст анкеты отправляется в OpenAI API по кнопке «Сформировать с ИИ».

## 1. Запусти сайт на Windows

1. Распакуй `Medsap.zip`. Открой папку `Medsap`, в которой лежит `app.py`.
2. Нажми на адресную строку Проводника, набери `powershell` и нажми Enter. Откроется терминал в нужной папке.
3. Выполни `py --version`. Подойдёт Python 3.10 или новее. Если команда не найдена, установи Python с [официального сайта](https://www.python.org/downloads/windows/) и заново открой терминал. Если у тебя работает `python --version`, используй `python` вместо `py` в первой команде ниже.
4. Вводи команды по одной. Первая создаёт отдельное окружение для проекта, вторая скачивает пакеты, третья запускает сайт.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

5. Открой в браузере `http://127.0.0.1:5000`. Нажми «Подставить пример», потом «Сформировать сводку». Терминал должен оставаться открытым. Чтобы остановить сервер, нажми `Ctrl+C` в терминале.

Окружение создаётся один раз. При следующем запуске достаточно `.\.venv\Scripts\python.exe app.py` из папки проекта. Если порт 5000 занят, измени `port=5000` в последней строке `app.py` на `port=5001` и открой `http://127.0.0.1:5001`.

Для macOS и Linux команды эквивалентны.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

## 2. Как работает код

| Файл | Что в нём происходит |
| --- | --- |
| `templates/index.html` | Это форма и карточка. У поля жалоб есть `name="symptoms"`. Под этим именем браузер отправляет текст в Python. Записи вида `{{ values.symptoms }}` заполняются сервером при открытии страницы. |
| `static/style.css` | Размеры, цвета и расположение блоков. На широком экране карточка справа, на узком она ниже формы. |
| `app.py` | Flask принимает открытие страницы (`GET`) и отправку анкеты (`POST`). `request.form.get(...)` получает введённый текст. Python проверяет поля, вызывает нужную функцию из `agent.py` и возвращает страницу с результатом. |
| `agent.py` | `build_demo_summary` раскладывает текст по разделам. `build_ai_summary` отправляет анкету и инструкцию в API. Схема `ExtractedIntake` задаёт поля ответа. Python сверяет цитаты с исходной анкетой и показывает только вопросы из заданного списка. |
| `prompt.txt` | Стартовая инструкция для модели. Её можно заменить в этом файле. |

Проследи один пример. Когда введёшь «Болит голова» и нажмёшь кнопку, браузер отправит поле `symptoms`. Функция в `agent.py` вернёт текст для одноимённого раздела, а шаблон покажет его под заголовком «Жалобы».

Для первого изменения найди в `templates/index.html` подсказку «Например, болит голова…», поменяй её, перезапусти сервер и обнови страницу. Затем измени текст вымышленной анкеты в `DEMO_FORM` внутри `app.py` и снова нажми «Подставить пример».

## 3. Подключи ИИ

Для этого шага нужен собственный [ключ OpenAI API](https://platform.openai.com/api-keys) с доступом к модели. Ключ вводится только на твоём компьютере. Храни его вне кода и не отправляй в чат или командный репозиторий.

Останови сервер через `Ctrl+C`. В том же PowerShell задай ключ для текущего окна и запусти сайт заново.

```powershell
$env:MEDSAP_OPENAI_API_KEY = "ВСТАВЬ_СВОЙ_КЛЮЧ"
.\.venv\Scripts\python.exe app.py
```

В macOS и Linux вместо первой строки используй `export MEDSAP_OPENAI_API_KEY='ВСТАВЬ_СВОЙ_КЛЮЧ'`, затем запусти `.venv/bin/python app.py`.

Обнови страницу, нажми «Подставить пример» и «Сформировать с ИИ». По умолчанию используется `gpt-5.4-mini`. Если нужен другой доступный идентификатор модели с поддержкой структурированного ответа, задай `MEDSAP_OPENAI_MODEL` аналогично ключу. Появление кнопки с ИИ означает, что ключ задан. Успешная сводка с пометкой «С ИИ» подтверждает, что запрос прошёл. Если запрос завершится ошибкой, введённая анкета останется на экране, и можно будет повторить запрос или создать сводку без ИИ.

## 4. Проверь работу сайта

1. Нажми «Подставить пример» и сформируй сводку без ИИ. Все заполненные поля должны появиться в карточке.
2. Сотри жалобы и снова отправь форму. Браузер должен предложить заполнить обязательное поле.
3. Если ключ настроен, отправь вымышленный пример кнопкой с ИИ. При ошибке API форма должна сохранить введённый текст и предложить повторить запрос или выбрать режим без ИИ.
